## 📚 Selected Projects

### 🔸 Turbulent Channel Flow — DNS vs RANS vs Mixing-Length  
Comparison between DNS data at \(Re_\tau=5200\), RANS \(k\text{-}\varepsilon\) computations,  
and classical mixing-length theory.  
**Tech:** Python, NumPy, Matplotlib, ANSYS Fluent

### 🔸 Turbulent Entrainment — Coherent Structures (Imperial MSc Project)  
Characterisation of entrainment mechanisms and identification of Lagrangian structures.  
**Tech:** Python, SciPy, Matplotlib, FFT/Wavelets

### 🔸 CFD — Numerical Methods for Compressible Flows  
Finite-volume solver for the 1D Euler equations (Roe, HLLC, MUSCL).  
Shock tubes, convergence studies, stability analysis.  
**Tech:** MATLAB, Python

### 🔸 Flow Instability & Transition  
Numerical solution of the Orr–Sommerfeld equation, eigenvalue analysis,  
growth of Tollmien–Schlichting waves.  
**Tech:** MATLAB

### 🔸 Orbital Mechanics  
Two-body and restricted three-body dynamics. Stationary points,  
Lyapunov orbits, trajectory optimisation.  
**Tech:** Python
